# Avito CRM Bot

Telegram-бот, превращающий Telegram в CRM для обработки чатов Avito сетью
филиалов ломбарда «Гудда»: распределение чатов по точкам, мгновенные
уведомления, ответы клиентам прямо из Telegram (текст и фото), AI-черновики
ответов, управление сменами и ролевая модель для сотрудников/руководителей.

## Возможности

**CRM и поток сообщений**
- Фоновый поллинг всех Avito-аккаунтов, уведомления в реальном времени
- Фильтрация уведомлений по точкам, за которыми закреплён сотрудник
- Режим смены («💼 На смене» / «🛌 Отдыхаю») — не теряет доступ, просто не отвлекает
- Ответы клиентам текстом и фото прямо из Telegram, с защитой от двойной отправки
- «📩 Непрочитанные» и «🕒 Недавние (60 мин)» списки чатов
- «⏰ Отложить» — снять с непрочитанных, но получить напоминание через 2 часа/утром
- «🗑 Удалить сообщение» — на случай ошибочного ответа

**ИИ-ассистент**
- «🧠 ИИ-ответ» — черновик по всему контексту диалога через tooken.club (Responses API)
- Жёсткий запрет на любые цены/оценки стоимости — по промпту и отдельным regex-фильтром поверх
- AI-промпт-шаблоны: точечные пресеты, которые настраивает ответственный за точку

**Роли и админ-панель**
- Роли: 🧑‍💼 Сотрудник точки, 📋 Ответственный точки, 🛡 РОП, 👑 Админ
- Одобрение/мгновенная блокировка заявок, «👥 Все пользователи», рассылки
- Опциональный платный вход за Telegram Stars, с возвратом при отказе
- Управление Avito-аккаунтами, точками (импорт с Avito по координатам объявлений),
  ключом ИИ и прокси для Telegram — всё редактируется из бота, без правки кода
- Ежедневные резервные копии БД прямо в Telegram

**Профиль**
- «👤 Мой профиль» с рейтингом (1 балл = 1 отправленный ответ) и общим топом

## Архитектура

Python 3.12+, `aiogram` 3, SQLite (`aiosqlite`), без ORM и без обязательного
внешнего API-сервера — весь стейт в одном файле БД.

```
main.py            entrypoint: лок от двойного запуска, старт/остановка
config.py          .env + сборка Bot (с опциональным прокси)
database.py        aiosqlite слой, миграции (migrations/)
bot_cache.py        SmartCache — независимое in-memory хранилище чатов
avito_client.py     клиент Avito Messenger API
ai_client.py        клиент tooken.club (Responses API)
guardrail.py        защита от утечки цен в AI-черновиках
tasks.py             фоновый поллинг Avito, снузы, бэкапы
handlers.py           CRM-роутеры: меню, чаты, шаблоны, админка
ai_handlers.py         роутер AI-черновиков
keyboards.py, filters.py, states.py, models.py, constants.py, utils.py
```

`bot_cache.py` и `avito_client.py` — независимые модули-синглтоны без
зависимости друг от друга, поэтому фоновый поллер (`tasks.py`) и обработчики
кнопок (`handlers.py`/`ai_handlers.py`) импортируют их напрямую, не завязываясь
друг на друга.

## Установка

Подробная пошаговая инструкция (SSH и FTP+SSH) — в [`DEPLOY.md`](./DEPLOY.md).

Коротко: нужен Linux-сервер (Debian/Ubuntu) с Python 3.12+ и systemd, токен
бота от [@BotFather](https://t.me/BotFather), venv + `pip install -r
requirements.txt`, заполненный `.env` (см. `.env.example`) и
`avito_bot.service` в systemd. Всё остальное (Avito-аккаунты, ключ ИИ,
прокси) настраивается после первого запуска прямо в боте, в «⚙️ Настройки».

## Известные ограничения

Пути и формат запросов Avito Messenger API и Responses API tooken.club —
best-effort по документации, без живых креденшелов на момент написания;
требуют проверки на реальном аккаунте перед продакшн-запуском. Детали и
полный список допущений — в комментариях `avito_client.py`/`ai_client.py` и
в плане реализации.
